# Sentinel Purge — Check First, Change Nothing Without Your Tap

Sentinel Purge is a phone bench that starts read-only: storage intake, cache and storage checks, popup check, malware flags, and plain reports you can read. Cleanup is a plan first (dry run), then your confirmation, then it runs.

## Testers wanted

Sign up, run it on a phone you own, and submit your test data so results can be checked. You need a phone you own and a computer to run it from.
