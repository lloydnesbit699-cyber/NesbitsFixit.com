## Veli'Thra qo'choH

Reality, rearranged. Veli'Thra is a browser extension that lets you move, resize, recolor, and rename the controls on any website — in your own browser, on your own machine. Your layouts save only to your own computer. Nothing is uploaded, nothing is shared, and the website itself is never changed.

Plans:

- Free — save layouts on 1 website, forever.
- Basic — save layouts on 3 websites.
- Pro — unlimited websites.
- Lifetime — unlimited websites, forever.
- Founder Lifetime — unlimited websites, forever. Available through December 22, 2026.

Veli'Thra is live now — install it free from the Chrome Web Store and start rearranging. Paid plans open soon.

- Chrome Web Store: https://chromewebstore.google.com/detail/velithra-qochoh/plfjjlfpcmelagpcmofnhcegbejdbmll
- Interactive demo: https://crumbsvault.com/showcase/velithra/
